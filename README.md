# Mahashankh ESP32 Smart Environmental Sentinel

## Overview
This project is an ESP32-based Smart Environmental Sentinel developed during the Mahashankh Embedded Systems Internship.

## Objective
To monitor environmental parameters using DHT22 and implement ultra-low-power operation using ESP32 Deep Sleep mode.

## Components Used
- ESP32 DevKit V1
- DHT22 Sensor
- SSD1306 OLED Display
- LED
- Piezo Buzzer
- Jumper Wires

## Features
- Temperature and Humidity Monitoring
- OLED Display
- Serial Telemetry
- LED and Buzzer Alert
- Deep Sleep Mode
- NVS (Non-Volatile Storage)
